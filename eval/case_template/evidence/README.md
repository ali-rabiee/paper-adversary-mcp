Put the evidence pack's full texts here: one file per prior paper, named in case.yaml. Plain extracted text
(.md or .txt) is used as is; a .pdf or arXiv .html file is extracted once by `paper-adversary eval prepare`,
so every run of a pair reads the same bytes. Keep only papers you are allowed to store (e.g. arXiv preprints
for personal research use) and do not redistribute them.
